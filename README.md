# Odin Recipes

## About This Project
This is a basic recipe website built as the first project in [The Odin Project's](https://www.theodinproject.com/) Foundations curriculum. The goal of this project is to build a multi-page website from scratch using only raw HTML. It serves as a practical, hands-on application of fundamental web development concepts before moving on to CSS and styling. 

## Skills Demonstrated
By building this project, I have successfully practiced and demonstrated the following skills:
* Setting up standard HTML5 boilerplate structures.
* Organizing page content using proper heading hierarchy (`<h1>` through `<h6>`) and paragraphs (`<p>`).
* Emphasizing text using `<strong>` and `<em>` tags.
* Creating ordered (`<ol>`) and unordered (`<ul>`) lists for recipe instructions and ingredients.
* Implementing relative links to navigate between local project pages, and absolute links to reference external sources.
* Embedding images (`<img>`) and using `alt` attributes for accessibility.
* Using Git for version control and pushing the project to a remote GitHub repository.
